# 小红书 · 表格模式（摸鱼）

把小红书伪装成一份 Excel 在线表格：**一帖一行，图片变成「图01」这样的文字链接，点开才看原图。**

单文件油猴脚本，零依赖，约 3200 行原生 JS。

> 版本 `0.1` ｜ 作者 **BOB** ｜ [开发文档](DEV.md)

## 特性

- **首页接管**：瀑布流 → 表格，左侧行号、顶部 A/B/C 列号、标题栏工具栏公式栏一应俱全，页面标题变成「工作簿1」
- **详情接管**：主贴第 1 行，评论按楼层往下排；楼中楼带 `↳ 回复 @某人` 和层级缩进
- **图片全量**：主贴所有图片列成「图01…图N」，点开看原图。不管轮播只渲染了几张，都能列全
- **评论折叠 + 分批**：默认只露第一条回复，按钮显示「展开 195 条回复」；点开后变「再加载几条（已 10/195）」，点一次多一批
- **搜索过滤**：顶部搜索框按作者 / 标题筛选，不破坏原数据
- **登录 / 登出**：调起原生登录浮窗；登出是真的退出账号，不是关掉表格
- **赞 / 收藏 / 回复**：调起原生按钮；脚本点不动时用红框圈住按钮引导真人点一下
- **安全阀**：`Ctrl+Shift+X` 一键收起所有浮层，`Esc` 关闭当前层
- **自动更新**：自带本地更新源，Tampermonkey 定期拉新版

## 安装

1. 浏览器装 **Tampermonkey**（油猴）。
2. **任选一种**装脚本：
   - 打开 `http://127.0.0.1:8125/install.html`，点绿色按钮；
   - 或直接把 `xiaohongshu-fishy.user.js` 拖进浏览器窗口；
   - 或 Tampermonkey → 添加新脚本 → 粘贴 `xiaohongshu-fishy.user.js` 全文。
3. 打开 `xiaohongshu.com`，按 `Ctrl+Shift+R` 强刷。

> **关于自动更新**：脚本头部的 `@updateURL` / `@downloadURL` 指向本机 `127.0.0.1:8125`。
> 如果你没有跑这个本地服务（`serve.mjs`），这两行连不上 —— **无害**，只是不会自动更新。
> 不想看到无用的更新请求，可以把那两行删掉。

## 使用

### 首页

| 操作 | 效果 |
|---|---|
| 点「图01」 | 看原图，点别处关闭 |
| 点行的空白处 | 进入该笔记，变成详情表格 |
| 顶部搜索框 | 按作者 / 标题过滤 |
| 点「加载更多」行 / 滚到底 | 让小红书加载下一批 |

### 详情页

| 操作 | 效果 |
|---|---|
| `Esc` | 关闭详情回列表 |
| 点「展开 N 条回复」 | 展开这一楼，默认只露第一条 |
| 点「再加载几条（已 10/195）」 | 继续拉下一批（小红书一次给 10 条） |
| 点「赞 / 收藏」 | 切到原生界面并用红框圈住目标按钮，点一下后表格自动回来 |
| 点「回复」 | 切到原生界面并聚焦输入框，直接打字 |

### 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl + Shift + X` | 一键收起所有浮层 |
| `Esc` | 关闭当前浮层 |

## 已知限制

1. **点赞 / 收藏必须真人点一下。** 小红书的按钮会校验事件来源（`event.isTrusted`），脚本合成的点击会被丢弃。所以脚本只能把按钮用红框圈给你。
2. **回复要切到原生界面**才能输入（同上原因）。
3. **游客只能看到约 30 条。** 这是小红书未登录的限制，不是脚本问题。
4. **搜索结果页游客态为空**（提示"登录后查看搜索结果"），登录后正常接管。
5. **小红书改版会失效。** DOM 结构一变，抓取就可能错位，需要跟着更新。

## 出问题了怎么查

按 F12 打开 Console：

```js
document.documentElement.dataset.fzWhy
```

| 返回 | 含义 |
|---|---|
| `ok` | 正常接管 |
| `warmup` | 刚进页面，等数据中 |
| `busy` | 表格已打开 |
| `closed` | 你手动关过这篇，不会自动弹 |
| `no-data` | 页面里没找到笔记数据 |
| `list` | 当前不是详情页 |
| `throw:...` | 渲染报错，后面是错误信息 |

更细的排查：

```js
window.__fzProbe            // 一组只读函数
__fzProbe.readNotePage()    // 看看它读到的标题/正文/图片
__fzProbe.readComments()    // 看看评论树
__fzProbe.readStateNote(id) // 看看从站点数据里解析出的笔记
```
